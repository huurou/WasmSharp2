# 命令定義から一覧と実行の振り分けを生成する

2026-09-06の`wasm-runtime-foundation`の設計確認で、基盤の段階からコード生成を導入し、命令ごとの宣言と処理を正本として命令一覧と単一の`switch`実行ループの振り分けを生成する方式を採用した。[ADR 0002](0002-single-pass-linear-interpreter.md)が定める、命令情報の唯一の定義元と単一の実行ループを具体化する判断である。

命令情報と`switch`をそれぞれ手で修正して整合を確認する案に対し、後続の数値命令やSIMDの追加時に二重管理を生じさせないことを優先した。生成処理の実装・保守が増える不利益を受け入れる。正本の具体的な記法と生成ツールの方式は、後続の設計で確定する。

同日の追加確認で、コード生成は通常のビルドで自動実行し、生成物はビルド中間出力として扱うことを確定した。生成コマンドの別途実行や生成済みソースの管理を要求せず、命令定義を変更した際の生成し忘れによる不整合を防ぐ。
