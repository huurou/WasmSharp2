# ホストからmemoryへは範囲を指定して読み書きする

ホスト向けmemory操作は範囲を指定したバイトの読み書きとし、内部領域を直接参照するSpan等の借用ビューは公開しない。直接アクセスを公開する案に対し、同期再入やmemoryの増大をまたぐビューの寿命・有効性を利用者が管理する必要をなくすことを優先する。

読み出したバイトはホスト側のコピーであり、その後のmemoryの変化には追従しない。共有するWasmMemory実体への各読み書きは、その操作時点の領域を対象とする。この判断はホスト操作の公開契約を定めるものであり、内部の記憶領域の構成やguest命令の実装方式は定めない。
